# Spring Boot REST API

This project demonstrates a Spring Boot RESTful application built using layered architecture and best practices.

## 🔧 Tech Stack
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- REST APIs
- Maven

## 📌 Features
- RESTful API design
- Request validation
- Centralized exception handling
- Layered architecture (Controller, Service, Repository)
- Database interaction using JPA

## 🧱 Architecture
- Controller Layer – Handles HTTP requests
- Service Layer – Business logic
- Repository Layer – Database access

## 🚀 Purpose
This project showcases backend development skills aligned with enterprise Java applications.
